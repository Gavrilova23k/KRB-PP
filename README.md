# Туризм по городам России

Веб-приложение для изучения крупных городов России с аутентификацией, погодным прогнозом и системой отзывов.
В приложении есть аутентификация по почте и паролю Имя можете ввести любое Почта для теста : test@example.com Пароль: 12345678 Над погодой ведется доработка еще, всё остальное в целом будет выглядеть так как есть, может какие-то мелкие доработки

## 🛠 Стек технологий

| Категория | Технология | Зачем |
|-----------|-----------|-------|
| **Framework** | Next.js 16 (App Router) | SSR, маршрутизация, API routes |
| **Язык** | TypeScript | Статическая типизация, безопасность кода |
| **БД** | SQLite + Drizzle ORM | Простая реляционная база данных |
| **API** | tRPC | Типизированные запросы между клиентом и сервером |
| **Аутентификация** | Кастомная (better-sqlite3 + bcryptjs) | Регистрация, вход, сессии через куки |
| **UI** | Кастомный CSS | Градиенты, анимации, адаптив |
| **Погода** | Open-Meteo API | Бесплатный прогноз погоды без API ключа |
| **Тесты** | Vitest + React Testing Library | Unit и интеграционные тесты |

### Почему эти технологии?

| Решение | Обоснование |
|---------|-------------|
| **tRPC вместо REST** | Автоматическая типизация API, меньше boilerplate, интуитивная разработка |
| **Drizzle ORM** | Лёгкий, быстрый, TypeScript-first, поддержка миграций |
| **Кастомная auth** | Полный контроль над сессиями, нет привязки к внешнему провайдеру |
| **App Router** | Современный подход Next.js, server components, проще маршрутизация |
| **SQLite** | Простота для разработки и деплоя на Vercel/Netlify |

### Ключевые архитектурные решения

| Решение | Почему | Альтернатива |
|---------|--------|--------------|
| **tRPC вместо REST** | Автоматическая типизация API, меньше boilerplate, интуитивная разработка | REST + OpenAPI, GraphQL |
| **Drizzle ORM** | Лёгкий, быстрый, TypeScript-first, поддержка миграций | Prisma, TypeORM |
| **Кастомная auth** | Полный контроль над сессиями, нет привязки к внешнему провайдеру | NextAuth.js, Clerk, Auth0 |
| **App Router** | Современный подход Next.js, server components, проще маршрутизация | Pages Router |
| **SQLite** | Простота для разработки и деплоя на Vercel/Netlify | PostgreSQL, MySQL |

## 📦 Установка и запуск

### Предварительные требования

- Node.js 18+ (рекомендуется 20 LTS)
- npm 9+ или yarn
- Git

### Быстрый старт

```bash
# 1. Клонируйте репозиторий
git clone <your-repo-url>
cd tourism-app

# 2. Установите зависимости
npm install

# 3. Настройте переменные окружения
cp .env.example .env.local
# Отредактируйте .env.local при необходимости

# 4. Инициализируйте базу данных (создаёт таблицы и начальные данные)
npm run db:init

# 5. Запустите сервер разработки
npm run dev
